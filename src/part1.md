# 第一部分：基础与框架

**架构定位：全书的地基。** 这三章不涉及具体实现代码，而是建立理解后续所有章节的认知框架。

在深入具体的记忆机制之前，我们需要先建立三件事：

1. **全景认知** — Agent Memory 是什么？为什么在 2023 年成为一个独立研究领域？领域的边界和核心问题是什么？
2. **统一语言** — 用一个本体论框架（三维正交分类 + 类层级）来描述所有记忆概念，避免术语混乱和概念重叠。
3. **认知锚点** — 从人类记忆模型出发，理解为什么本书按"感知→短期→长期→程序性"的顺序组织。

这三章是全书的基础。后续每一章都会使用第2章建立的本体论语言来分析具体技术。

**与全书架构的关系：** 第一部分对应记忆系统的"设计图纸"层——在建造之前先理解要建什么、用什么语言描述它。第16章的综合案例会反复回引这里的概念。
