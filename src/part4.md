# 第四部分：程序性记忆层

**架构定位：记忆系统的智能层。** 程序性记忆让 Agent 从"记住"进化到"学会"——从经验中提炼策略，从失败中反思改进。

程序性记忆是 Agent "知道怎么做"的记忆——工具使用、策略选择、经验积累。它不同于"知道什么"的陈述性记忆，而是关于能力和技能的记忆。

这一部分回答三个问题：
- 程序性记忆在 Agent 中如何表示和存储？
- 如何构建一个能从经验中学习、不断进化的 Agent？
- 记忆如何跨越时间和用户实现个性化？

**与全书架构的关系：** 第四部分是第16章综合案例 V3 的核心——添加经验库和用户画像。它让 Agent 从"有记忆的应答机器"变成"会学习的助手"。每章都包含独立的代码实现。
