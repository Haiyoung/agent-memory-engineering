# 第二部分：短期记忆层

**架构定位：记忆系统的前线。** 所有信息首先进入短期记忆层，这里是记忆生命周期中最高频、最实时的操作层。

短期记忆是 Agent 记忆的"前线"——所有信息首先进入这里，被筛选、压缩、分配注意力，然后决定是遗忘还是进入长期存储。

这一部分回答三个问题：
- LLM 的上下文窗口能作为记忆吗？它的本质和边界是什么？
- 当上下文溢出时，如何主动管理信息的压缩与保留？
- 如何设计一个可运行的工作记忆管理器？

**与全书架构的关系：** 第二部分是第16章综合案例 V1 的核心——最小可行记忆。它是记忆系统最容易实现、最直接见效的层，但单独使用无法解决跨会话和持久化问题。
