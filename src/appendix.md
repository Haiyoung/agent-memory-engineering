## B. 术语对照表

以下术语从 Agent Memory 领域本体论（ontology_base.md v1.1）中提取，涵盖载体、功能、动态、核心类、治理和架构范式六个类别，共计 56 个核心术语。

### 载体维度（Carrier Dimension）

| 中文术语 | English Term | 定义 |
|---------|-------------|------|
| 记忆载体 | Memory Carrier | 记忆的物质承载形式，分为标记级、参数级、外部级和隐式级 |
| 标记级记忆 | Token-level Memory | 以文本令牌为载体的记忆，驻留于模型的输入上下文中 |
| 参数级记忆 | Parametric Memory | 以模型权重为载体的记忆，通过训练或编辑将知识内化于参数中 |
| 外部记忆 | External Memory | 以外部存储为载体的记忆，独立于模型本身持久化于外部数据库中 |
| 隐式记忆 | Latent Memory | 以隐式表示为载体的记忆，存在于模型的隐藏状态或潜在表征中 |
| 上下文窗口 | Context Window | LLM 在单次推理中能够处理的令牌数量上限，本质是输入缓冲区而非记忆 |
| 向量数据库 | Vector Database | 存储和检索高维嵌入向量的外部存储系统，如 FAISS、ChromaDB |
| 知识图谱 | Knowledge Graph | 以实体-关系三元组组织的结构化知识表示 |
| 记忆流 | Memory Stream | 以自然语言线性记录所有观察和交互经验的数据结构 |

### 功能维度（Function Dimension）

| 中文术语 | English Term | 定义 |
|---------|-------------|------|
| 事实记忆 | Factual Memory | 存储离散客观信息的记忆，如用户偏好、世界常识 |
| 语义记忆 | Semantic Memory | 组织概念关联与知识网络的记忆，如知识图谱、概念层级 |
| 情景记忆 | Episodic Memory | 记录交互事件与时间线索的记忆，如对话历史、交互轨迹 |
| 程序记忆 | Procedural Memory | 存储可执行技能与操作流程的记忆，如工具调用序列、SOP |
| 经验记忆 | Experiential Memory | 记录成功/失败轨迹与迁移知识的记忆，如反馈诊断、启发式策略 |
| 工作记忆 | Working Memory | 即时认知工作区，承载当前任务处理所需的活跃信息 |

## D. Agent Memory 框架选型速查表

### D.1 一页纸决策图

```
你的场景是什么？
│
├─ 多个 Agent 共享记忆 → 中心化记忆服务
│   ├─ 需要生产级/企业级 → Redis Agent Memory Server
│   ├─ 需要 LLM 自动管理 → Mem0
│   ├─ 需要知识图谱 → Zep, Forgetful
│   └─ 需要用户档案 → Supermemory
│
├─ 单个 Agent 内嵌记忆 → SDK 嵌入
│   ├─ 基于 LangGraph → LangMem
│   ├─ 框架无关 → Agent Memory OS
│   └─ 认知科学建模 → OpenMemory
│
├─ 需要记忆版本控制 → Memoria
├─ 需要多模态记忆 → MemOS
└─ Agent 自主管理记忆 → MemGPT (Letta)
```

### D.2 按记忆类型需求选型

| 需求 | 必需的记忆类型 | 推荐方案 |
|------|--------------|---------|
| 会话持久化 | 工作记忆 + 短期记忆 | LangGraph Checkpoint |
| 跨会话知识 | 语义记忆 + 情景记忆 | Mem0 / Redis AMS |
| 用户画像 | 偏好记忆 + 语义记忆 | Supermemory / Claude Code Auto Memory |
| 程序技能 | 程序记忆 | MemOS / OpenMemory |
| 时间推理 | 时序记忆 | Zep / OpenMemory Temporal KG |
| 知识关联 | 图谱记忆 | Forgetful / Memoria / OpenMemory |
| 实验/分支 | 版本化记忆 | Memoria |

### D.3 按技术栈约束选型

| 约束 | 影响 |
|------|------|
| 已有 Redis 基础设施 → 优先 Redis AMS |
| 使用 LangGraph 框架 → 优先 LangMem（原生集成） |
| 需要本地优先 → Forgetful / OpenMemory / Hermes Agent |
| 需要 MCP 协议 → 7 个项目原生支持 |
| 生产级多租户 → Memoria (per-user DB) / MemOS (cube access control) |

### D.4 存储后端速查

| 场景 | 推荐后端 | 理由 | 代表项目 |
|------|---------|------|---------|
| 原型开发 | SQLite / 内存 | 零依赖、易调试 | LangGraph InMemorySaver |
| 生产-通用 | PostgreSQL + pgvector | 成熟、向量+关系一体 | MemGPT, MemOS |
