# 前言

> 记忆是智能体的第四支柱——感知让它看见世界，规划让它理解目标，行动让它改变世界，而记忆让它成为"自己"。

大语言模型（LLM）的革命性能力已经毋庸置疑。然而，一个根本性缺陷始终存在：每次推理都从零开始。没有记忆，就没有真正的智能体——只有不断重置的应答机器。

这本书解决的就是这个问题。

我们基于对 170 篇 Agent Memory 领域论文的系统性分析，提出了一个统一的本体论框架，涵盖 1092+ 个概念、五种架构范式、六个生命周期阶段。全书按认知科学的记忆分类组织，从短期记忆到长期记忆，从程序性记忆到反思记忆，每一层都有清晰的理论框架和可操作的工程方案。

这不是一本纯理论的书，也不是一本纯教程。它试图在两者之间架起桥梁——用本体论建立统一语言，用全景地图建立认知框架，用工程决策指南建立行动能力。

如果你是一名研究者，你可以从本书中获得对 Agent Memory 领域的系统性理解。如果你是一名工程师，你可以从本书中获得构建记忆系统的实用方案。如果你两者都是——这正是我们写书时想到的读者。

## 如何使用本书

- 如果你只需要短期记忆方案，读第一、二部分即可
- 如果你需要完整的长期记忆系统，请从第一部分开始
- 如果你在做架构选型，直接跳到第十五章的工程决策地图
- 如果你想看到一个完整系统的构建过程，阅读第十六章的综合案例
- 每章末尾都有延伸阅读，指向更深入的论文和技术资料

## 本书范围

本书聚焦于 **Agent Memory 的理论框架与工程实践**——即如何为 LLM 智能体设计和构建记忆系统。具体涵盖：

- Agent Memory 的本体论框架和统一分析语言
- 短期记忆（上下文窗口）、长期记忆（向量/图存储）、程序性记忆（工具/经验）的分层设计
- 每层的完整代码实现与运行示例
- 记忆治理规范（TTL、质量控制、隐私保护）
- 架构选型决策指南
- 一个完整的记忆增强研究助手的渐进式构建过程

**本书不覆盖：**
- LLM 训练与微调——记忆是外部架构问题，不是参数问题
- 具体业务场景的深度定制（如医疗、金融、法律等专业领域）
- LLM 本身的架构改进（如注意力机制优化、MoE 设计）
- 非 Agent 场景的记忆系统（如推荐系统中的用户画像）

## 前置假设

本书面向有一定技术背景的读者。为获得最佳阅读体验，建议读者具备：

- **Python 编程基础**：能阅读和理解 Python 类/函数代码（数据类、装饰器、异步编程）
- **机器学习基础**：了解 LLM 的基本工作原理（自回归生成、注意力机制、上下文窗口）
- **数据库基础**：了解向量数据库和图数据库的基本概念

如果你不具备上述基础，建议先阅读延伸阅读中推荐的入门资料。
