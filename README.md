# 智能体记忆工程 — Agent Memory Engineering

> 记忆是智能体的第四支柱——感知让它看见世界，规划让它理解目标，行动让它改变世界，而记忆让它成为"自己"。

一本关于 **Agent Memory 理论框架与工程实践**的中文技术书籍。基于 170 篇领域论文的系统性分析，涵盖记忆系统设计的完整闭环——从认知科学的基础理论到可运行的工程实现。

## 章节结构

### 第一部分：基础与框架（第 1-3 章）

全书地基，建立理解后续所有章节的认知框架。

- **第 1 章 · Agent Memory 全景地图** — 领域起源、五种架构范式与五大功能范式、2021-2026 年演进轨迹
- **第 2 章 · 本体论框架** — 三维正交分类体系，1092+ 概念的统一描述语言
- **第 3 章 · 认知科学映射** — 从 Atkinson-Shiffrin 模型到全局工作空间理论，人类记忆如何启发 Agent 设计

### 第二部分：短期记忆层（第 4-6 章）

记忆系统的"前线"——最高频、最实时的操作层。

- **第 4 章 · 上下文窗口作为记忆** — 上下文窗口的本质、边界与优化策略
- **第 5 章 · 上下文压缩与注意力分配** — 滑动窗口、语义压缩、摘要压缩、记忆槽压缩四种策略
- **第 6 章 · 工作记忆管理器（实践）** — 完整可运行的 MemoryManager 实现，含滑动窗口管理、语义压缩、动态上下文组装

### 第三部分：长期记忆层（第 7-10 章）

Agent 区别于普通 LLM 的核心——跨会话、跨时间的持久化知识存储。

- **第 7 章 · 情景记忆与语义记忆** — 事件记忆与知识记忆的区分，MemReader 主动提取范式
- **第 8 章 · 记忆存储架构选型（实践）** — 向量库 vs 知识图谱 vs 混合方案，HyperMem 超图记忆架构
- **第 9 章 · 检索增强与多跳推理** — HingeMem 查询自适应检索、多跳推理链路设计
- **第 10 章 · 构建记忆增强对话系统（实践）** — HybridRetriever + ContextInjector 完整实现

### 第四部分：程序性记忆层（第 11-13 章）

让 Agent 从"记住"进化到"学会"——从经验中提炼策略，从失败中反思改进。

- **第 11 章 · 经验、技能与工具使用记忆** — ToolMemory 实现，SkillX 技能知识图谱
- **第 12 章 · 自我反思与经验积累系统（实践）** — ReflectionLoop + ExperienceStore，MemCoT 测试时记忆扩展
- **第 13 章 · 跨会话学习与个性化** — CrossSessionMemory + 用户画像演化

### 第五部分：治理与前沿（第 14-16 章）

记忆系统的运维、安全与未来方向。

- **第 14 章 · 记忆治理** — 记忆编辑、遗忘策略、隐私保护（MEXTRA 攻击框架）、安全共享（INMS 协议）
- **第 15 章 · 工程决策地图与未来展望** — 架构选型指南、Large Memory Models、测试时记忆、多模态记忆
- **第 16 章 · 综合案例：记忆增强的个人研究助手（实践）** — V1→V4 渐进式构建，四层记忆 + 反思循环 + 治理策略的完整系统
